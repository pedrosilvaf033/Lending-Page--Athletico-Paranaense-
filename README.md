# Cap+ | Landing Page Promocional 🔴⚫

Landing page promocional desenvolvida para o plano combo **CapPlus**, integrando os serviços Furacão100 e CapTv em homenagem ao centenário do Club Athletico Paranaense.

---

## 💻 Sobre o Projeto

O projeto consiste em uma página web responsiva construída durante práticas de desenvolvimento front-end (baseada no layout Alura+). A página apresenta:
- Apresentação dos planos e botões de chamada para ação (CTA).
- Destaques de funcionalidades (escalação do time e transmissão de jogos).
- Seção de compatibilidade com dispositivos (TV, Computador, Celular).
- Layout responsivo e estilização com identidade visual rubro-negra.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página (`<header>`, `<section>`, `<footer>`).
- **CSS3:** 
  - CSS Grid e Flexbox para organização do layout.
  - Variáveis CSS (Custom Properties) para paleta de cores.
  - Pseudo-classes (`:hover`, `:active`) para interatividade nos botões e links.
- **Google Fonts:** Tipografia utilizando a fonte *Inter*.
